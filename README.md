# 🎥 vidFlow

vidFlow é uma plataforma de vídeos desenvolvida com HTML, CSS e JavaScript, que utiliza uma API simulada (JSON Server) para carregar e exibir vídeos de forma dinâmica.

## 🌟 Recursos

* 🎬 Interface inspirada em plataformas de streaming modernas
* 🔄 Carregamento dinâmico de vídeos via API
* 🧭 Navegação simples e intuitiva
* ⚡ Leve, responsivo e rápido
* 🛠️ Código aberto e fácil de personalizar

## 🧩 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (ES6+)
* JSON Server

## 🚀 Instalação e Uso

### 🔧 1. Clonar o repositório

```bash
git clone [https://github.com/seu-usuario/vidFlow.git](https://github.com/seu-usuario/vidFlow.git)
```

### 📂 2. Acessar o diretório do projeto

```bash
cd vidFlow
```

### 🧠 3. Instalar o JSON Server
Se ainda não tiver o JSON Server instalado globalmente, execute:

```bash
npm install -g json-server
```

### ▶️ 4. Iniciar o servidor da API
No diretório raiz do projeto, execute:

```bash
json-server --watch backend/videos.json
```
O servidor será iniciado (por padrão) em:
```bash
http://localhost:3000
```

### 🌐 5. Abrir o projeto
Abra o arquivo index.html no seu navegador ou use a extensão Live Server (VS Code).

# 🌍 English Version

# 🎥 vidFlow
vidFlow is a video platform built with HTML, CSS, and JavaScript, using a fake API (JSON Server) to dynamically load and display videos.

## 🌟 Features
* 🎬 Modern, streaming-inspired UI
* 🔄 Dynamic video loading via API
* 🧭 Simple and intuitive navigation
* ⚡ Lightweight, responsive, and fast
* 🛠️ Open source and easy to customize

## 🧩 Tech Stack
* HTML5
* CSS3
* JavaScript (ES6+)
* JSON Server

## 🚀 Installation and Usage

###🔧 1. Clone the repository
```bash
git clone [https://github.com/your-username/vidFlow.git](https://github.com/your-username/vidFlow.git)
```

### 📂 2. Enter the project folder
```bash
cd vidFlow
```

### 🧠 3. Install JSON Server
If you don’t have JSON Server installed globally, run:
```bash
npm install -g json-server
```

### ▶️ 4. Run the API server
Inside the project root, execute:
```bash
json-server --watch backend/videos.json
```
The server will start (by default) at:
```bash
http://localhost:3000
```

### 🌐 5. Open the project
Open the index.html file in your browser or use Live Server in VS Code.
